# Icon

> ไอคอนจาก **registry ปิด** — `stroke` ผูกกับขนาดโดยบังคับ ไม่มี prop ให้ override

`Icon` ไม่ใช่ตัวห่อ `lucide-react` แบบบาง ๆ · มันเป็น **ทะเบียน** ที่ทำให้ระบบรับประกันสองอย่างที่ตัวห่อบาง ๆ รับประกันไม่ได้: ชุดไอคอนถูกจำกัดไว้เฉพาะที่ตรวจแล้ว และเส้นทุกเส้นหนาสัมพันธ์กับขนาดอย่างสม่ำเสมอ

---

## 1 · เมื่อไหร่ใช้อะไร

| | ใช้ |
|---|---|
| ไอคอนในกระแสเนื้อหา · คู่กับข้อความ | `<Icon name="check" />` |
| ปุ่มที่มีแต่ไอคอน | [`<IconButton>`](../inputs/IconButton.md) — **ไม่ใช่** `<Icon>` ในปุ่ม |
| สัญลักษณ์รับรองไทย (มอก. · ฮาลาล · GMP · ThaID · PromptPay) | **ข้อความ** หรือโลโก้จริงจากผู้ออกใบรับรอง — ห้ามหยิบไอคอนใกล้เคียง |

⚠️ `import { X } from 'lucide-react'` **ถูกห้ามด้วย lint** — ต้องผ่าน `<Icon name="x" />` เท่านั้น เพราะ `registry.ts` ต้องเป็น static import map · ถ้า import ตรงหรือใช้ dynamic import ด้วยตัวแปร bundler จะรวมไอคอน Lucide ทั้ง ~1,600 ตัวเข้า bundle

---

## 2 · Props

| prop | type | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|---|
| `name` | `IconName` | — | **บังคับ** — key ของ registry (27 ตัว) ดู [`registry.ts`](./registry.ts) |
| `size` | `16 \| 20 \| 24 \| 32 \| 48` | `20` | เลือกจาก **font-size** ของข้อความข้าง ๆ ไม่ใช่ line-height |
| `label` | `string` | — | มีค่า = สื่อความหมาย · ไม่มีค่า = ตกแต่ง (ดู §4) |

`strokeWidth` · `stroke` · `fill` · `width` · `height` · `role` · `aria-label` ถูก **ถอดออกจาก type** — ตั้งไม่ได้เลย

> **ทำไมชื่อ `name` ไม่ใช่ `icon`** — Astryx ใช้ `icon` ที่รับ `ReactNode` ส่วนของเรารับ key ของทะเบียน ซึ่งเป็นสิ่งที่ทำให้การรับประกันใน §3 เป็นไปได้ · `name` สื่อ "อ้างถึงรายการในทะเบียน" ตรงกว่า (`ASTRYX-PARITY.md` → **D37**)

## 3 · stroke ผูกกับขนาด

Lucide วาดบนตาราง 24px ด้วย `stroke 2` · ถ้าใช้ 2 ทุกขนาด สัดส่วนเส้นต่อกล่องจะห่างกัน **3 เท่า** ทำให้ไอคอน 16px ดูหนากว่าตัวอักษร 13px ที่วางข้างกัน — กลับลำดับความสำคัญ

| size | stroke | เส้น/กล่อง |
|---|---|---|
| 16 | 1.5 | 9.38% |
| 20 | 1.75 | 8.75% |
| 24 | 2 | 8.33% |
| 32 | 2.5 | 7.81% |
| 48 | 2.5 | 5.21% |

ช่วงห่างเหลือ **1.8 เท่า** · ค่าเดียวกับ `--icon-stroke-*` ใน [`semantic.css`](../../../02-tokens/src/semantic.css)

**ไม่ทำให้คงที่เป๊ะ 8.33% โดยตั้งใจ** — 16px ต้องใช้ 1.33 ซึ่งบนจอ 1× DPI จะถูกปัดบางกว่า 1px แล้วเสี่ยงไม่ผ่าน 3:1 · 48px ต้องใช้ 4 ซึ่งทำให้ไอคอนกลายเป็นภาพประกอบหนา ไม่ใช่สัญลักษณ์

### การจับคู่ขนาดกับข้อความ

| font-size ข้าง ๆ | `size` |
|---|---|
| 13–14px | 16 |
| 16–18px | 20 |
| 20–24px | 24 |
| 28–32px | 32 |

## 4 · สื่อความหมาย vs ตกแต่ง

เส้นแบ่งอยู่ที่ `label` เพียงตัวเดียว และ **ต้องเลือก** — ไม่มีค่ากลาง

```tsx
{/* ตกแต่ง — มีข้อความอยู่ข้างแล้ว → aria-hidden อัตโนมัติ */}
<span><Icon name="check" size={16} /> อนุมัติแล้ว</span>

{/* สื่อความหมาย — ไอคอนเป็นข้อมูลเดียวที่มี → role="img" + aria-label */}
<Icon name="shield-check" size={20} label="ยืนยันตัวตนแล้ว" />
```

| | ผลที่ได้ | เกณฑ์ contrast |
|---|---|---|
| ไม่มี `label` | `aria-hidden="true"` | ไม่มี — screen reader ข้าม |
| มี `label` | `role="img"` + `aria-label` | **3:1** (SC 1.4.11) · ที่ 16px แนะนำ **≥4.5:1** เพราะ stroke 1.5px บางกว่าตัวอักษร |

⚠️ `label` ต้องเป็นภาษาไทย และถ้ามีข้อความที่มองเห็นอยู่ ต้อง **รวมข้อความนั้นด้วย** (SC 2.5.3 Label in Name)

## 5 · สิ่งที่ registry ตั้งใจไม่มี

Lucide **ไม่มี**ไอคอนสำหรับสิ่งที่ SME.GO เป็นเรื่องเกี่ยวกับจริง — ThaID · PromptPay · e-Tax · DBD · มอก. · ฮาลาล · GMP

ตามข้อ 09 ของชั้น 01: **ใช้ข้อความแทน ห้ามหยิบไอคอนที่ใกล้เคียงมาใช้** เพราะไอคอนที่ความหมายผิดแย่กว่าไม่มีไอคอน — และบนแพลตฟอร์มภาครัฐ ไอคอนที่สื่อว่า "รับรองแล้ว" โดยไม่มีใครรับรอง **มีน้ำหนักทางกฎหมาย** · การรับรองจริงใช้ [`<CertificationBadge>`](../marketplace/SellerProfile.md) ที่รับไฟล์โลโก้จริงพร้อม `alt` เป็นชื่อเต็มของการรับรอง

## 6 · กับดัก

| อย่าทำ | ทำแบบนี้ | เพราะ |
|---|---|---|
| `<Icon name="x" size={18} />` | `size={20}` | 18 ไม่อยู่ในชุด — ไม่มี stroke ที่ล็อกไว้ |
| `<Icon ... strokeWidth={2} />` | เปลี่ยน `size` | prop ถูกถอดจาก type แล้ว (ตั้งใจ) |
| `<button><Icon name="search" /></button>` | [`<IconButton>`](../inputs/IconButton.md) | ปุ่มไอคอนล้วนต้องมี accessible name + เป้า ≥44px |
| ใส่ `label` ทุกตัว | ใส่เฉพาะตอนไอคอนเป็นข้อมูลเดียว | screen reader จะอ่านซ้ำกับข้อความข้าง ๆ |
| ไอคอนแทนสัญลักษณ์รับรองไทย | ข้อความ หรือโลโก้จริง | §5 |
