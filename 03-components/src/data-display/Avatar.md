## 1 · ภาพรวม

โลโก้หรือรูปประจำตัวผู้ขาย พร้อม **ทางถอย 3 ชั้น**:

```
src → fallbackSrc → ตัวย่อจาก name → ไอคอน building
```

### ❌ เมื่อไรที่ไม่ควรใช้

| สถานการณ์ | ใช้อะไรแทน | เหตุผล |
|---|---|---|
| รูปสินค้า | [`<CardMedia>`](./Card.md) | สินค้าไม่ใช่ตัวตน · ต้องเป็น 4:3 ไม่ใช่วงกลม |
| ป้ายยืนยันตัวตน | [`<Badge variant="success">`](./Badge.md) | ส่งเป็น `status` เข้ามาแทน |
| แกลเลอรีรูป | [`<ImageGallery>`](./ImageGallery.md) | |
| ระหว่างโหลด | [`<Skeleton shape="circle">`](../feedback/Skeleton.md) | |

## 2 · React API

```tsx
import { Avatar } from '@smego/ui';

// เคสปกติ — ชื่ออยู่ข้าง ๆ แล้ว จึงไม่ต้องส่ง alt
<Avatar src={seller.logo} name={seller.name} size="lg" />

// avatar เดี่ยว ไม่มีชื่อเป็นข้อความ → ต้องส่ง alt
<Avatar src={seller.logo} alt={`โลโก้ ${seller.name}`} />
```

| prop | type | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|---|
| `src` | `string` | — | URL รูปหลัก |
| `fallbackSrc` | `string` | — | ใช้เมื่อ `src` โหลดไม่ขึ้น |
| `name` | `string` | — | ทำตัวย่อ · **ไม่** กลายเป็น `alt` (ดู §5) |
| `alt` | `string` | `''` | `''` = ของตกแต่ง — ดู §5 |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 24 / 40 / 48 / 96px |
| `status` | `ReactNode` | — | มุมล่างขวา เช่นป้ายยืนยันตัวตน |
| `className` | `string` | — | |

**`initialsFromName(name)`** export แยกไว้ด้วย — ใช้เมื่อต้องแสดงตัวย่อที่ตรงกันในที่อื่น

## 3 · Variants

| `size` | px | คลาส | ใช้ที่ |
|---|---|---|---|
| `sm` | 24 | `size-6` | ในแถวรายการ · `CartSellerGroup` |
| `md` | **40** | `size-10` | ในการ์ด (ค่าเริ่มต้น) |
| `lg` | 48 | `size-12` | หัวโปรไฟล์ผู้ขาย — ขนาดที่ใช้อยู่เดิม |
| `xl` | 96 | `size-24` | หน้าโปรไฟล์เต็ม |

Astryx ให้ทั้งชื่อ (`xsm`…`xl`) และตัวเลข 14 ค่า — เราให้ชื่ออย่างเดียวด้วยเหตุผลเดียวกับ `Grid preset` (D22): ระบบตัดสินให้แล้ว ไม่ส่งคำถามกลับไปที่ call site

`xsm` 20px ของเขาถูกตัดเพราะ **cluster ไทยที่มีสระบนล่างอ่านไม่ออกที่ขนาดนั้น**

## 4 · States

| state | ผล |
|---|---|
| มี `src` และโหลดขึ้น | รูป `object-cover` |
| `src` พัง | ลอง `fallbackSrc` |
| พังทั้งคู่ (หรือไม่มี `src`) | ตัวย่อจาก `name` |
| ไม่มี `name` ด้วย | ไอคอน `building` |

**ไม่มีสถานะ "กล่องเปล่า"** — ทุกทางถอยแสดงอะไรบางอย่างเสมอ เพราะวงกลมเทาว่างในหน้ารายการผู้ขายอ่านเป็น "โหลดไม่เสร็จ" ทั้งที่โหลดเสร็จแล้ว

## 5 · Accessibility

| เรื่อง | ข้อกำหนด |
|---|---|
| **SC 1.1.1** | `alt=""` เมื่อเป็นของตกแต่ง · ตัวย่อและไอคอนเป็น `aria-hidden` เสมอ |
| **SC 4.1.2** | `alt` ที่ส่งมายังประกาศแม้รูปจะถอยไปเป็นตัวย่อ |

### ★★ `alt` ไม่ถอยไปใช้ `name` — ต่างจาก Astryx โดยเจตนา (D25)

Astryx ให้ `alt` ถอยไปใช้ `name` อัตโนมัติ · **เราไม่ทำ** เพราะเคสที่พบจริงเกือบทั้งหมดคือ avatar วางข้างชื่อที่เป็นข้อความอยู่แล้ว:

```tsx
<Avatar src={logo} name={seller.name} />
<h3>{seller.name}</h3>     {/* ← ชื่ออยู่ตรงนี้แล้ว */}
```

ถ้า `alt` = ชื่อ ผู้ใช้ screen reader จะได้ยิน **ชื่อผู้ขายสองครั้งติดกัน**

ระบบนี้ตัดสินเรื่องเดียวกันมาแล้วสามที่ และเลือก "ประกาศครั้งเดียว" ทุกครั้ง — จำนวนในตะกร้า ([`TopNav`](../navigation/TopNav.md)) · ปุ่มปิด [`Banner`](../feedback/Banner.md) · ปุ่มลบ [`RemovableChip`](./Token.md)

⚠️ **ผลที่ตามมาที่ผู้เรียกต้องรู้:** ถ้าแสดง avatar **โดยไม่มีชื่อเป็นข้อความใกล้ ๆ** (เช่นแถวรูปผู้ขายเรียงกัน) **ต้องส่ง `alt` เอง** ไม่งั้นข้อมูลหาย

### ตัวย่อเป็น `aria-hidden` เสมอ

ตัวย่อคือ**ภาพแทนชื่อ ไม่ใช่ข้อมูลใหม่** — ถ้าไม่ซ่อน ผู้ใช้ screen reader จะได้ยิน `"ไ"` ลอย ๆ ก่อนชื่อจริง

## 6 · ★★★ ตัวย่อจากชื่อไทย — เหตุผลหลักที่ component นี้มีอยู่

ตัวย่อแบบฝรั่งใช้กับชื่อไทยไม่ได้ และพังสองชั้น **โดยไม่มี error ให้เห็น**

### ชั้น 1 · ตัดสตริงดิบทำให้สระและวรรณยุกต์หลุด

| ชื่อ | `name[0]` (ผิด) | grapheme cluster (ถูก) |
|---|---|---|
| `กำแพงเพชรอาหารสัตว์` | `ก` — สระ `ำ` หลุด | **`กำ`** |
| `ห้างทองไทยเจริญ` | `ห` — วรรณยุกต์ `้` หลุด | **`ห้`** |
| `ร้านกาแฟดอยคำ` | `ร` — วรรณยุกต์ `้` หลุด | **`ร้`** *(ก่อนตัดคำนำ)* |

ต้องใช้ `Intl.Segmenter` granularity `grapheme` — ตัวอักษรไทยหนึ่งตัวที่ผู้อ่านเห็นประกอบจากหลาย code point

### ชั้น 2 · ชื่อนิติบุคคลไทยขึ้นต้นด้วยคำบอกประเภทกิจการ

| ชื่อ | ถ้าไม่ตัดคำนำ | หลังตัด |
|---|---|---|
| `บริษัท ไทยโรสเตอร์ จำกัด` | `บ` | **`ไ`** |
| `บริษัท ขอนแก่นเกษตร จำกัด` | `บ` ← **ซ้ำ** | **`ข`** |
| `ห้างหุ้นส่วนจำกัด สมชายการค้า` | `ห้` | **`ส`** |
| `หจก. ขอนแก่นเกษตร` | `ห` | **`ข`** |

ผู้ขายไทยส่วนใหญ่จะได้ตัวย่อเดียวกันหมด — **avatar ที่แยกกันไม่ออกคือ avatar ที่ไม่ทำงาน**

คำที่ตัด (เรียง**ยาวไปสั้น** เพราะ `ห้างหุ้นส่วนจำกัด` ต้องชนก่อน `ห้างหุ้นส่วน`):

```
ห้างหุ้นส่วนจำกัด · ห้างหุ้นส่วนสามัญ · ห้างหุ้นส่วน · บริษัทจำกัด · บริษัท
หจก. · บมจ. · บจก. · บจ. · ร้าน · กลุ่ม · วิสาหกิจชุมชน · สหกรณ์
```

ถ้าตัดแล้วไม่เหลืออะไร (ชื่อเป็นคำบอกประเภทล้วน) จะใช้ชื่อเดิม — ไม่คืนค่าว่าง

### ชื่อฝรั่งใช้กฎอีกแบบ

**สองตัวแรกของสองคำแรก** หลังตัดคำต่อท้าย (`Co.` `Ltd` `Inc` `Corp` `LLC` `PLC` `Company` `Limited`)

`Thai Roaster Co.` → **`TR`** · `Acme` → **`A`**

ตัวย่อสองตัวไม่ใช่ธรรมเนียมไทย และสระบนล่างซ้อนกันสองชุดจะล้นวงกลม จึงใช้ **cluster เดียว** สำหรับไทย

## 7 · Tailwind implementation

```tsx
{/* ⚠️ overflow-hidden อยู่ชั้น**ใน** */}
<span className="relative inline-flex shrink-0">
  <span className="inline-flex items-center justify-center overflow-hidden rounded-full
                   bg-sunken text-fg-secondary border border-edge size-10">
    …
  </span>
  {status && <span className="absolute -bottom-0.5 -end-0.5">{status}</span>}
</span>
```

### ★★ `overflow-hidden` ต้องอยู่ชั้นใน ไม่ใช่ชั้นนอก

รูปต้องถูก clip เป็นวงกลม แต่ `status` วางล้นขอบออกไป — ถ้า `overflow-hidden` อยู่ชั้นนอก **ป้ายจะถูกตัดหายไปทั้งอัน** เทส `"status ต้องไม่ถูกตัด"` ล็อกข้อนี้ไว้

### พื้นเป็น `bg-sunken` ไม่ใช่สีแบรนด์

"พื้นทึบน้ำเงิน = กดได้" ถูกสงวนไว้ให้ปุ่ม (ข้อ 05) · avatar กดไม่ได้ — ถ้าอยู่ในลิงก์ ตัวลิงก์เป็นคนรับ affordance

`border border-edge` กันรูปโลโก้สีอ่อนละลายไปกับพื้นการ์ด

## 8 · Figma Variant

Component set **`Avatar`**

| Property | Values |
|---|---|
| `Size` | `sm (24)` · **`md (40)`** · `lg (48)` · `xl (96)` |
| `Content` | **`Image`** · `Initials (ไทย)` · `Initials (Latin)` · `Icon` |
| `Status` | **`None`** · `Badge` |

**`Initials (ไทย)` ต้องใช้ชื่อจริงที่มีสระบนล่าง** เช่น `กำ` หรือ `ห้` — ถ้าใช้แต่ `ก` นักออกแบบจะตั้ง line-height ที่ตัดหัวสระทิ้งโดยไม่รู้ตัว

## 9 · Anti-patterns

| ❌ | ✅ | ทำไม |
|---|---|---|
| `<img className="size-12 rounded-full">` | `<Avatar size="lg">` | ไม่มีทางถอยตอนรูปพัง |
| `name.slice(0, 2)` ทำตัวย่อเอง | `initialsFromName()` | สระ/วรรณยุกต์หลุด · ได้ `บ` ซ้ำกันทุกราย |
| `alt={seller.name}` ตอนมีชื่ออยู่ข้าง ๆ | ไม่ส่ง `alt` | ได้ยินชื่อสองครั้ง |
| ไม่ส่ง `alt` ตอน avatar อยู่เดี่ยว | ส่ง `alt` | ข้อมูลหายทั้งหมด |
| `bg-primary-600` เป็นพื้นตัวย่อ | `bg-sunken` | น้ำเงินทึบสงวนให้ปุ่ม |
| `overflow-hidden` ชั้นนอก | ชั้นใน | `status` ถูกตัดหาย |
| `-right-0.5` | `-end-0.5` | กลับด้านไม่ได้ |
| `<Avatar>` สำหรับรูปสินค้า | [`<CardMedia>`](./Card.md) | สินค้าไม่ใช่ตัวตน · ต้อง 4:3 |

## 10 · Quality Checklist

**หลักฐาน ไม่ใช่ความตั้งใจ** — ทุกแถวชี้ไปที่หัวข้อในไฟล์นี้หรือชื่อเทสที่รันได้จริง

| รายการ | สถานะ | หลักฐาน |
|---|---|---|
| การเข้าถึง (Accessibility) | ✅ | §5 · axe ผ่านใน `a11y/avatar.test.tsx` ทุกทางถอย · เทส "ค่าเริ่มต้นเป็นของตกแต่ง" และ "ตัวย่อเป็น aria-hidden" |
| ตอบสนอง (Responsive) | ✅ | `shrink-0` — avatar ต้องไม่ถูกบีบเป็นวงรีในแถว flex ที่แคบ · ขนาดคงที่เป็น px โดยเจตนา (เป็นวงกลม) |
| โหมดมืด (Dark Mode) | ✅ | `lint-classes.mjs` 0 จุด — `bg-sunken` / `border-edge` / `text-fg-secondary` override ในโหมดมืดแล้ว |
| คุณสมบัติเชิงตรรกะ (Logical properties) | ✅ | `-end-0.5` ไม่ใช่ `-right-0.5` · เทส "ใช้ -end-* ไม่ใช่ -right-*" ล็อกไว้ |
| คีย์บอร์ด (Keyboard) | — | ไม่ใช่ตัวควบคุม ไม่อยู่ใน tab order · ถ้าต้องกดได้ให้ห่อด้วย [`<Link>`](../inputs/Link.md) |
| กำลังโหลด (Loading) | ✅ | §4 · ทางถอย 3 ชั้น · ระหว่างโหลดหน้าให้ใช้ [`<Skeleton shape="circle">`](../feedback/Skeleton.md) |
| ข้อผิดพลาด (Error) | ✅ | §4 · `onError` เลื่อนชั้นทางถอย — เทส "src พัง → fallbackSrc" และ "พังทั้งคู่ → ตัวย่อ" |
| ว่างเปล่า (Empty) | ✅ | ไม่มีสถานะว่าง — ไอคอน `building` เป็นชั้นสุดท้าย |
| Skeleton | ✅ | `Skeleton shape="circle"` มีอยู่แล้วและ radius ตรงกัน |
| การเคลื่อนไหว (Animation) | — | ไม่มี `transition` ในไฟล์นี้ · avatar ไม่เปลี่ยนสถานะจากการโต้ตอบ |
| ประสิทธิภาพ (Performance) | ✅ | `object-cover` ป้องกันรูปบิด · ไม่มีความสูงตายตัวที่ทำให้ CLS (`size-*` คงที่ทั้งกล่องตั้งแต่ render แรก) |
