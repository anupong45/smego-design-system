# ImageGallery

**`@smego/ui`** · ชั้น 03 · [ImageGallery.tsx](./ImageGallery.tsx)

---

## 1 · ภาพรวม

รูปสินค้าในหน้ารายละเอียด — รูปหลักหนึ่งใบ + แถวรูปย่อที่ **กดเปลี่ยนได้ ไม่เลื่อนเอง**

### ❌ เมื่อไรที่ไม่ควรใช้

| สถานการณ์ | ใช้อะไรแทน | เหตุผล |
|---|---|---|
| รูปเดียวบนการ์ด | [`<CardMedia>`](./Card.md) | ไม่มีอะไรให้เลือก |
| แบนเนอร์โปรโมชัน | วางเป็นรูปธรรมดา | ไม่ใช่ของที่ผู้ใช้ต้องตรวจสอบ |
| เอกสารหลายหน้า | ลิงก์ดาวน์โหลด PDF | ผู้ใช้ต้องซูมและพิมพ์ได้ |

## 2 · React API

```tsx
<ImageGallery
  itemName="เครื่องคั่วกาแฟ TR-500"
  images={[
    { src: '/p/tr500-1.jpg', alt: 'เครื่องคั่วกาแฟ TR-500 ด้านหน้า' },
    { src: '/p/tr500-2.jpg' },
  ]}
/>
```

| prop | type | หมายเหตุ |
|---|---|---|
| `images` | `GalleryImage[]` | ว่าง = ไม่ render อะไรเลย |
| `itemName` | `string` | **บังคับ** — ใช้เติม `alt` ที่ผู้ขายไม่ได้กรอก |

### GalleryImage

| field | type | หมายเหตุ |
|---|---|---|
| `src` | `string` | รูปเต็ม |
| `alt` | `string` | ไม่ส่ง = "ชื่อสินค้า รูปที่ n" |
| `thumbnailSrc` | `string` | ไม่ส่ง = ใช้ `src` |

## 3 · Variants

ไม่มี variant · จำนวนรูปเป็นตัวกำหนดรูปแบบ

| จำนวนรูป | ผล |
|---|---|
| `0` | `return null` |
| `1` | รูปหลักอย่างเดียว ไม่มีแถวรูปย่อ |
| `≥ 2` | รูปหลัก + แถวรูปย่อที่เลื่อนแนวนอนได้ |

## 4 · States

| state | ตัวชี้ |
|---|---|
| รูปที่กำลังดู | `aria-current="true"` + ขอบ `edge-brand` |
| รูปอื่น | ขอบ `edge` · hover เป็น `edge-strong` |

**ขอบเป็น 2px ทั้งสองสถานะ** — ถ้าเปลี่ยนความหนา ความกว้างของรูปย่อจะกระโดดทุกครั้งที่เลือก และแถวจะขยับทั้งแถว

## 5 · Accessibility

| เรื่อง | ข้อกำหนด |
|---|---|
| **SC 2.1.1** | รูปย่อเป็น `<button>` จริง Tab ถึงทุกใบ |
| **SC 4.1.3** | ประกาศ "รูปที่ 2 จาก 5" ผ่าน `aria-live="polite"` |
| **SC 1.1.1** | รูปหลักมี `alt` เสมอ · รูปย่อเป็น `alt=""` เพราะชื่อปุ่มพูดแทนแล้ว |
| **SC 2.2.2** | **ไม่มีการเลื่อนอัตโนมัติ** |
| **SC 2.4.7** | แถวที่เลื่อนได้มี `p-1 -m-1` เผื่อวงแหวน focus |

### ★★★ ไม่มี carousel ที่เลื่อนเอง

ระบบประกาศกฎ "ไม่มีอะไรหายไปตามเวลา" ไว้แล้วในหลายที่ (Tooltip · นับถอยหลัง QR · Toast ที่ถูกจำกัดขอบเขต)

รูปที่เลื่อนเองทำให้ผู้ใช้ที่กำลังดูรายละเอียดสินค้าเสียตำแหน่ง และเป็นการเคลื่อนไหวอัตโนมัติที่ต้องมีปุ่มหยุดตาม SC 2.2.2 — ทางที่ถูกกว่าคือ **ไม่มีตั้งแต่แรก**

### ★★★ `alt` ที่เติมให้อัตโนมัติ ดีกว่า `alt=""`

ผู้ขายจำนวนมากไม่กรอกคำบรรยาย · ถ้าปล่อยเป็น `alt=""` รูปหลักจะหายไปจาก a11y tree ทั้งใบ และผู้ใช้ screen reader จะไม่รู้ด้วยซ้ำว่ามีรูปอยู่

`"เครื่องคั่วกาแฟ TR-500 รูปที่ 2"` ไม่ได้บรรยายรูป แต่บอกว่ากำลังดูอะไรและอยู่ตรงไหน ซึ่งเป็นข้อมูลจริงที่ตรวจสอบได้

### ★★ ชื่อปุ่มบอกตำแหน่ง ไม่ใช่ "รูปภาพ"

รูปย่อ 5 ใบที่ชื่อ "รูปภาพ" เหมือนกันหมดแยกไม่ออก (SC 2.5.3) · ชื่อจึงเป็น "รูปที่ 3 จาก 5"

### ★ ไม่มี lightbox ในรอบนี้

ถ้าต้องซูม ให้หน้าเปิด [`<Dialog>`](../feedback/Dialog.md) เอง — การซ้อน modal ไว้ในกล่องรูปทำให้ focus กลับผิดที่เมื่อปิด และ component รู้ไม่ได้ว่าควรคืน focus ไปที่รูปย่อใบไหน

## 6 · Tailwind implementation

```tsx
<img className="aspect-square w-full object-contain" />
```

`object-contain` ไม่ใช่ `object-cover` — สินค้าอุตสาหกรรมที่ถูกครอบตัดจะเสียสัดส่วนจริงซึ่งเป็นข้อมูลที่ผู้ซื้อใช้ตัดสินใจ · รูปย่อใช้ `object-cover` ได้เพราะเป็นแค่ตัวเลือก

```tsx
<ul className="-m-1 flex min-w-0 gap-2 overflow-x-auto p-1">
```

`overflow-x-auto` ตัดวงแหวน focus ที่ล้น 4px — `p-1 -m-1` คืนพื้นที่นั้นโดยไม่เปลี่ยน layout (ข้อ 05 §5)

## 7 · Figma Variant

Component set **`ImageGallery`**

| Property | Values |
|---|---|
| `Images` | `1` · `3` · **`8 (เลื่อนแถว)`** |
| `Ratio` | `จัตุรัส` · `รูปแนวนอนใน object-contain` |

## 9 · Anti-patterns

| ❌ | ✅ | ทำไม |
|---|---|---|
| carousel เลื่อนเอง | กดเปลี่ยนเท่านั้น | SC 2.2.2 · ผู้ใช้เสียตำแหน่ง |
| `<div onClick>` เป็นรูปย่อ | `<button>` | Tab ไม่ถึง · SR ไม่รู้ว่ากดได้ |
| `alt=""` บนรูปหลัก | เติมให้อัตโนมัติ | รูปหายจาก a11y tree ทั้งใบ |
| `alt="รูปภาพ"` | คำบรรยายหรือตำแหน่ง | ไม่ให้ข้อมูลอะไรเลย |
| รูปย่อมี `alt` ด้วย | `alt=""` | ชื่อซ้อนสองชั้น |
| "เลือกอยู่" ด้วยขอบสีอย่างเดียว | `aria-current` | SC 1.4.1 · SR ไม่รู้ว่าอันไหน |
| ขอบหนาขึ้นตอนเลือก | หนาเท่ากันเปลี่ยนแค่สี | แถวขยับทุกครั้งที่เลือก |
| `object-cover` บนรูปหลัก | `object-contain` | ครอบตัดสัดส่วนจริงของสินค้า |
| ไม่ประกาศตำแหน่งเมื่อเปลี่ยนรูป | `aria-live="polite"` | SC 4.1.3 |
