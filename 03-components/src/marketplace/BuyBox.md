## 1 · ภาพรวม

กล่องราคาและการสั่งซื้อในหน้ารายละเอียด — **สินค้าเข้าตะกร้า · บริการไม่เข้าตะกร้า**

⚠️ **ขอบเขต: component ไม่ใช่หน้า** — หน้ารายละเอียดประกอบเองจาก [`<ImageGallery>`](../data-display/ImageGallery.md) · [`<SellerProfile>`](./SellerProfile.md) · [`<DescriptionList>`](../data-display/DescriptionList.md) + กล่องนี้

### ❌ เมื่อไรที่ไม่ควรใช้

| สถานการณ์ | ใช้อะไรแทน | เหตุผล |
|---|---|---|
| ราคาบนการ์ดในหน้ารายการ | [`<EntityAmount>`](./EntityCard.md) | ต้องตรงแนวกับการ์ดใบอื่นและอ่านออกที่ 136px |
| สมัครทุน / สินเชื่อ | [`<GrantCard>`](./GrantCard.md) · [`<FundingCard>`](./FundingCard.md) | วงเงินสูงสุด ≠ ราคา |
| สรุปยอดก่อนจ่าย | [`<CheckoutSummary>`](./Checkout.md) | คนละขั้น |

## 2 · React API

```tsx
<BuyBox
  kind="product"
  name="เครื่องคั่วกาแฟ TR-500"
  price={1_250_000}
  unit="เครื่อง"
  moq={1}
  stock={4}
  onAddToCart={(qty) => add(qty)}
  isAdding={isAdding}
  errorMessage={error}
  secondaryAction={<SaveButton variant="full" itemName="เครื่องคั่วกาแฟ TR-500" />}
/>
```

| prop | type | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|---|
| `kind` | `'product' \| 'service'` | — | ★ **บังคับ ไม่มีค่าเริ่มต้น** |
| `name` | `string` | — | เข้าไปอยู่ในข้อความยืนยัน |
| `price` | `number \| null` | — | `null` = ขอใบเสนอราคา · `0` = ฟรีจริง |
| `unit` | `string` | — | ต่อท้ายราคาและเป็นหน่วยของช่องจำนวน |
| `priceNote` | `string` | — | "ต่อโครงการ" ฯลฯ |
| `moq` | `number` | `1` | สั่งขั้นต่ำ |
| `stock` | `number` | — | `0` = หมด · ไม่ส่ง = ผู้ขายไม่ระบุ |
| `onAddToCart` | `(quantity: number) => void` | — | เฉพาะ `product` |
| `isAdding` | `boolean` | `false` | ปุ่มขึ้น spinner กดซ้ำไม่ได้ |
| `onContact` | `() => void` | — | บริการ · และสินค้าที่หมด |
| `errorMessage` | `string` | — | `<Banner>` ไม่ใช่ `<Toast>` |
| `secondaryAction` | `ReactNode` | — | ปุ่มบันทึก ฯลฯ |

## 3 · Variants

| `kind` | ราคา | ตัวควบคุม | CTA |
|---|---|---|---|
| `product` | ราคา / หน่วย | `<NumberInput>` จำนวน | **เพิ่มลงตะกร้า** |
| `service` | ค่าบริการ หรือ "ขอใบเสนอราคา" | ไม่มี | **ติดต่อผู้ขาย** + ข้อความว่าไม่มีตะกร้า |

### ★★★ `kind` ไม่มีค่าเริ่มต้นโดยตั้งใจ

การเดาผิดเปลี่ยนเส้นทางการซื้อทั้งเส้น · TypeScript บังคับให้เลือกตอนเขียน ไม่ใช่ให้รู้ตัวตอนมีคนกดสั่งบริการแล้วได้ใบแจ้งค่าขนส่ง

## 4 · States

| state | ที่มา | ผล |
|---|---|---|
| ปกติ | `stock > 0` | ช่องจำนวน + "เพิ่มลงตะกร้า" |
| **สินค้าหมด** | `stock === 0` | `<Badge>` "สินค้าหมด" + ปุ่มเปลี่ยนเป็น **"สอบถามกำหนดมีของ"** |
| ผู้ขายไม่ระบุสต็อก | `stock === undefined` | ไม่มี badge · สั่งได้ตามปกติ |
| กำลังเพิ่ม | `isAdding` | spinner · กดซ้ำไม่ได้ (RAC `isPending`) |
| ผิดพลาด | `errorMessage` | `<Banner tone="danger" isLive>` เหนือปุ่ม |
| ไม่มีราคา | `price === null` | "ขอใบเสนอราคา" แทนตัวเลข |

### ★★ สินค้าหมด **ไม่ได้** ทำให้กล่องนี้เทาทั้งใบ

ผู้ซื้อ B2B ยังต้องดูสเปก เทียบราคา และถามว่าจะมีของเมื่อไร — ปุ่มจึง **เปลี่ยนหน้าที่** ไม่ใช่กลายเป็นปุ่มที่กดไม่ได้

ปุ่ม disabled ที่ไม่บอกทางออกคือทางตันของเส้นทางการซื้อทั้งเส้น

## 5 · Accessibility

| เรื่อง | ข้อกำหนด |
|---|---|
| **SC 1.4.1** | สถานะสต็อกมีทั้งไอคอนและข้อความใน `<Badge>` |
| **SC 3.3.1** | ข้อผิดพลาดเป็น `<Banner isLive>` ไม่ใช่ toast |
| **SC 3.3.2** | สั่งขั้นต่ำเป็น `description` ของช่อง ไม่ใช่แค่ `minValue` |
| **SC 2.5.8** | ปุ่ม `size="lg"` = 50px · ปุ่มเพิ่ม/ลด 24×24 |
| **SC 4.1.2** | ปุ่มกำลังทำงานใช้ RAC `isPending` ซึ่ง **คง focus ไว้** |

### ★★★ สั่งขั้นต่ำต้องเป็นข้อความ

`minValue` อย่างเดียวทำให้ช่องเด้งกลับเป็น 100 เงียบ ๆ ตอน blur — ผู้ใช้อ่านว่าระบบพัง ไม่ได้อ่านว่าเป็นกฎของผู้ขาย

`description` จึงบอกล่วงหน้า: **"สั่งขั้นต่ำ 100 ชิ้น"**

### ★★ ปุ่มกำลังทำงานต้องไม่ดีด focus

ใช้ `isLoading` ของ [`<Button>`](../inputs/Button.md) ซึ่ง map ไป RAC `isPending` — ปิดการกดแต่ **คง focus** และประกาศสถานะให้ screen reader

ถ้าใช้ `isDisabled` แทน focus จะตกไปที่ `<body>` และผู้ใช้คีย์บอร์ดหลุดกลับต้นหน้าทุกครั้งที่กดเพิ่มลงตะกร้า

### ★ ยืนยันสำเร็จเป็น Toast · ผิดพลาดเป็น Banner

เส้นแบ่งอยู่ใน [`Banner.md`](../feedback/Banner.md) — component นี้รับ `errorMessage` แต่ **ไม่รับ** `successMessage` เพราะความสำเร็จประกาศผ่าน `showToast` ที่ระดับหน้า และเห็นผลที่ตัวเลขบนไอคอนตะกร้าอยู่แล้ว

## 9 · Anti-patterns

| ❌ | ✅ | ทำไม |
|---|---|---|
| `kind` มีค่าเริ่มต้น | บังคับเลือก | เดาผิด = บริการเข้าตะกร้า |
| บริการมีปุ่ม "เพิ่มลงตะกร้า" | "ติดต่อผู้ขาย" | ราคายังไม่นิ่ง VAT/ค่าขนส่งจะผิด |
| สินค้าหมด → ปุ่มเทา | ปุ่มเปลี่ยนเป็นสอบถาม | ทางตันของเส้นทางการซื้อ |
| `price={0}` ตอนยังไม่รู้ราคา | `null` | `0` แปลว่าฟรีจริง |
| สั่งขั้นต่ำแค่ `minValue` | + `description` | ช่องเด้งกลับเงียบ ๆ อ่านว่าระบบพัง |
| `isDisabled` ตอนกำลังส่ง | `isLoading` | `disabled` ดีด focus หลุด |
| error เป็น toast | `<Banner isLive>` | ข้อความที่ต้องลงมือทำห้ามหายเอง |
| สถานะสต็อกเป็นสีอย่างเดียว | `<Badge>` มีไอคอน + ข้อความ | SC 1.4.1 |
| ราคาเป็นเลขไทย ๐–๙ | เลขอารบิก | กว้างต่างกัน 36.6% em |
