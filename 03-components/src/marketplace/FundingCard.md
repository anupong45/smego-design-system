# FundingCard

## 1 · ภาพรวม

การ์ดสินเชื่อ — **เงินที่ผู้รับต้องคืนเงินต้น** · สินเชื่อดอกเบี้ยพิเศษของรัฐ · soft loan · สินเชื่อ SME ของธนาคาร

### ★★★ เส้นแบ่งกับ `GrantCard` มีข้อเดียว

> **ผู้รับต้องคืนเงินต้นหรือไม่**
> คืน → `FundingCard` · ไม่คืน → `GrantCard`
> **เมื่อไม่แน่ใจ ใช้ `FundingCard`**

เกณฑ์อื่นที่พิจารณาแล้วและ **ทิ้ง** เพราะตัดเคสจริงไม่ได้:

| เกณฑ์ที่ทิ้ง | พังที่เคสไหน |
|---|---|
| "มีดอกเบี้ยไหม" | สินเชื่อดอกเบี้ย 0% จะกลายเป็นทุน — **ความผิดพลาดที่แพงที่สุดที่เป็นไปได้** |
| "ผู้ออกเป็นแบงก์หรือหน่วยงาน" | ทุน BOI ที่จ่ายผ่านธนาคารของรัฐจะกลายเป็นสินเชื่อ |

### เคสก้ำกึ่งที่ตัดสินไว้แล้ว

| เคส | การ์ด | เหตุผล |
|---|---|---|
| สินเชื่อดอกเบี้ย 0% ปลอดต้น 2 ปี | `FundingCard` | ยังคืนเงินต้น |
| ทุนที่ต้องคืนถ้าโครงการล้มเหลว | `FundingCard` | กฎเมื่อไม่แน่ใจ |
| สินเชื่อที่ยกหนี้ให้ถ้าจ้างงานครบเป้า | `FundingCard` | กฎเมื่อไม่แน่ใจ |
| เงินอุดหนุนร่วมจ่าย 50% | `GrantCard` | ร่วมจ่าย ≠ คืน |

**ทำไมกฎ "เมื่อไม่แน่ใจ" จึงเอนไปทางนี้** — เป็นการเลือกทิศทางของความผิดพลาดอย่างตั้งใจ เห็น "ทุน" แล้วรู้ทีหลังว่าเป็นหนี้ เสียหายกว่าเห็น "สินเชื่อ" แล้วรู้ทีหลังว่าไม่ต้องคืน · วิธีเดียวกับที่ `Badge.md` ปิดทางที่เสียหายกว่าด้วยกฎ "ทองไม่ใช่สถานะ"

### ❌ เมื่อไรที่ไม่ควรใช้

| สถานการณ์ | ใช้อะไรแทน | เหตุผล |
|---|---|---|
| ทุนให้เปล่า · เงินอุดหนุน | `<GrantCard>` | ไม่ต้องคืนเงินต้น |
| โครงการที่ไม่ให้เงิน | `<ProgramCard>` | ที่ปรึกษา · จับคู่ · พาออกงาน |
| หลักสูตรที่มีทุนเรียน | `<TrainingCard>` | สิ่งที่ขายคือหลักสูตร |
| บัตรเครดิตนิติบุคคล | `<ProductCard>` ของสถาบันการเงิน | วงเงินหมุนเวียน ไม่ใช่วงเงินกู้เป็นก้อน |

## 2 · React API

```tsx
import { FundingCard } from '@smego/ui';

<FundingCard
  href="/funding/d-scale"
  name="สินเชื่อ SME D-Scale"
  agency="ธนาคารพัฒนาวิสาหกิจขนาดกลางและขนาดย่อม"
  loanCeiling={1_250_000}
  interestRate={3}
  termMonths={84}
  collateral="bsy"
  status="closing-soon"
  daysLeft={7}
  footer={<Button fullWidth>ดูเงื่อนไข</Button>}
/>
```

| prop | type | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|---|
| `href` · `name` · `agency` | `string` | — | **บังคับ** |
| `loanCeiling` | `number` | — | **เพดานที่กู้ได้** ไม่ใช่ที่จะได้รับ |
| `interestRate` | `number \| null` | — | **บังคับ** · ต่อปี · `0` = ไม่มีดอกเบี้ย · `null` = ยังไม่ประกาศ |
| `termMonths` | `number \| null` | — | **บังคับ** · `null` = ยังไม่ประกาศ |
| `collateral` | `'none' \| 'required' \| 'bsy' \| null` | — | **บังคับ** · `null` = ยังไม่ประกาศ |
| `gracePeriodMonths` | `number` | — | ปลอดชำระเงินต้น |
| `guaranteeFeePercent` | `number` | — | ค่าธรรมเนียมค้ำประกัน บสย. ต่อปี |
| `deadline` | `string` | — | ISO `YYYY-MM-DD` (ค.ศ.) · สินเชื่อที่เปิดตลอดไม่ต้องส่ง |
| `status` | `DeadlineStatus` | — | **บังคับ** · เป็น prop ไม่ใช่ค่าคำนวณ |
| `daysLeft` | `number` | — | แสดงเมื่อ `closing-soon` |
| `media` · `actions` · `footer` | `ReactNode` | — | |
| `isSelected` · `headingLevel` · `as` | | | ส่งต่อไป `EntityCard` |

### ★★ สามค่าบังคับ และ `null` แปลว่า "ยังไม่ประกาศ"

`interestRate` · `termMonths` · `collateral` ต้องส่งเสมอ ตรรกะเดียวกับ `coPaymentPercent` ของ `GrantCard` — **การไม่แสดงกับการแสดงให้ข้อมูลต่างกันคนละเรื่อง**

แต่แหล่งข้อมูลของหน่วยงานมักไม่ครบ จึงรับ `null` ที่ **แสดงออกมาตรง ๆ ว่า "ยังไม่ประกาศ"** — ไม่ใช่ละไว้เงียบ ๆ

`null` เป็นข้อมูลที่มีประโยชน์จริง: SME ที่เห็น *"หลักประกัน — ยังไม่ประกาศ"* รู้ว่าต้องโทรถาม ต่างจากช่องว่างเปล่าที่อ่านว่า "ไม่มีเงื่อนไขนี้"

### ★ ทำไม `collateral` เป็น union 3 ค่า ไม่ใช่ `boolean`

*"ใช้ บสย. ค้ำแทนได้"* คือทางออกจริงของ SME ที่ไม่มีที่ดินค้ำ — `boolean` จะบีบเคสนี้ให้เป็น `true` (ต้องมี) ทำให้คนที่กู้ได้จริงเลิกสนใจไปเลย ซึ่งเป็นความเสียหายแบบเดียวกับที่ `GrantCard` ป้องกัน แค่กลับทิศ

ตรงกับกฎ `STYLE-GUIDELINE §5.2` — union type ไม่ใช่ `boolean`/`string` ค่าผิด compile ไม่ผ่าน

## 3 · Variants

`FundingCard` ไม่มี variant — ความต่างมาจากค่าที่ส่งเข้ามา เหมือน wrapper อื่นทั้ง 5 ตัว

### การแสดงผลของ `collateral`

| ค่า | ข้อความ |
|---|---|
| `'none'` | ไม่ต้องมีหลักประกัน |
| `'required'` | ต้องมีหลักประกัน |
| `'bsy'` | **ใช้ บสย. ค้ำประกันแทนได้** |
| `null` | ยังไม่ประกาศ |

### การแสดงผลของ `interestRate`

| ค่า | ข้อความ | ทำไม |
|---|---|---|
| `3` | `3% ต่อปี` | ★ **หน่วยเวลาบังคับ** — 3% ต่อเดือนกับต่อปีต่างกัน 12 เท่า |
| `0` | ไม่มีดอกเบี้ย | ต่างจาก "ยังไม่ประกาศ" คนละเรื่อง |
| `null` | ยังไม่ประกาศ | ห้ามเดาเป็น 0 |

### `termMonths` — หารด้วย 12 ลงตัวแสดงเป็นปี

`84` → `7 ปี` · `18` → `18 เดือน` · ผู้ใช้คิดเป็นปีเมื่อเป็นจำนวนปีเต็ม

## 4 · States

สืบทอดจาก `EntityCard` ทั้งหมด — **default · hover · focus-visible · active(pressed) · selected**

| state | ที่มา | รายละเอียด |
|---|---|---|
| default | `EntityCard` | ขอบ ไม่มีเงา |
| hover | `EntityCard` | เงาโผล่ (`06-shadow` — card ตอนพักไม่มีเงา) |
| focus-visible | `EntityCard` | ★ วงแหวนอยู่ที่**การ์ด** ไม่ใช่ลิงก์ — `line-clamp-2` จะตัดวงแหวน (SC 2.4.7) |
| active | `EntityCard` | — |
| selected | `isSelected` | อยู่ในการเปรียบเทียบ |
| **disabled** | ★ **ไม่มี** | การ์ดเป็นลิงก์ ไม่ใช่ปุ่ม · สินเชื่อที่ปิดรับใช้ `status="closed"` ซึ่งยังกดเข้าไปอ่านเงื่อนไขได้ |
| **loading** | ★ **ไม่มีในตัว** | ผู้เรียกใช้ `<SkeletonGroup>` ครอบกริด |
| **error** | ★ **ไม่มี** | การ์ดไม่ทำ async · ข้อมูลไม่ครบแสดงเป็น "ยังไม่ประกาศ" ไม่ใช่ error |
| **empty** | ★ **ไม่มี** | การ์ดที่ไม่มีข้อมูลไม่ถูก render ตั้งแต่ต้น |

> ★ การประกาศว่าไม่มี 4 state สุดท้ายคือข้อกำหนด ไม่ใช่การเว้นว่าง (`DESIGN-PRINCIPLES` A4(ก))

## 5 · Accessibility

| หัวข้อ | รายละเอียด |
|---|---|
| โครงสร้าง | `<article>` (หรือ `<li>` ในกริด `<ul>`) · หัวข้อระดับตาม `headingLevel` |
| ลิงก์ | overlay `after:absolute after:inset-0` — การ์ดทั้งใบกดได้ ไม่ใช้ `onClick` |
| focus | ★ วงแหวนที่การ์ด ไม่ใช่ที่ลิงก์ (SC 2.4.7) |
| `<dl>` | ทุกคู่มีชื่อกำกับ — SR ประกาศ "อัตราดอกเบี้ย, 3% ต่อปี" เป็นคู่ |
| SC 1.4.10 | ✅ ไม่มี horizontal scroll ที่ 320px |
| SC 1.4.13 | ✅ ไม่มีข้อมูลใดอยู่ใน tooltip |

### ★★ วัดที่ 136px — สัญญาของ `EntityCard`

| ตรวจอะไร | ผล |
|---|---|
| ชื่อทุกคู่ใน `<dl>` ไม่ถูกตัด | ✅ |
| `"วงเงินกู้สูงสุด"` อยู่ครบ ไม่ถูกตัด | ✅ |
| label อยู่**เหนือ**ตัวเลข ไม่ใช่ต่อท้าย | ✅ ยืนยันด้วยตำแหน่งจริง (`bottom ≤ top`) |
| ไม่มีข้อความอื่นล้นกล่อง | ✅ |

> ⚠️ **หนี้ที่รู้ตัว ไม่ใช่ของการ์ดใบนี้** — `EntityAmount` แสดงตัวเลข 7 หลัก (`1,250,000`) ที่ `text-title` กว้าง **109.47px** แต่กล่องในของการ์ดที่ 136px เหลือ **102px** → ล้น **7.47px**
>
> กระทบ **ทุกการ์ดที่มี `EntityAmount`** · มีเทส `test.fail()` ติดตามอยู่ใน `tests/e2e/pass4.spec.ts` — ถ้าวันใดแก้แล้ว เทสจะฟ้องให้มาลบทิ้ง

## 6 · Tailwind implementation

- ไม่มี CVA — เป็น wrapper ล้วน ส่งต่อไป `EntityCard` ทั้งหมด
- `EntityMeta` ประกอบแบบมีเงื่อนไข: `deadline` แทรกที่ตำแหน่งที่ 2 (`splice`) เพื่อให้ลำดับเป็น *หน่วยงาน → ปิดรับ → ดอกเบี้ย → ระยะเวลา → หลักประกัน* ซึ่งเรียงตามลำดับที่ผู้ใช้ถาม
- ตัวเลขทุกตัวห่อ `font-numeric` — ข้อความ "ยังไม่ประกาศ" ไม่ห่อ เพราะไม่ใช่ตัวเลข
- ทองใช้ได้ที่นี่เฉพาะ CTA ใน `footer` (ข้อ 02 §9) — การ์ดไม่บังคับสีปุ่ม

## 7 · Figma Variant

Component set `FundingCard`

| property | values |
|---|---|
| `State` | `Default` · `Hover` · `Focus` · `Selected` |
| `Status` | `open` · `closing-soon` · `closed` |
| `Collateral` | `none` · `required` · `bsy` · `not-announced` |
| `Data` | `Complete` · `Partial (nulls)` |

**ที่ห้ามลืม**

- **frame `Data = Partial (nulls)` ต้องมีจริง** — ถ้ามีแต่แบบข้อมูลครบ นักพัฒนาจะเดาว่าค่าที่ไม่มีให้ละไว้ ซึ่งขัดกฎข้อหลักของการ์ดนี้
- **frame `Width = 136` พร้อมเลข 7 หลัก** — ตามสัญญาของ `EntityCard`
- **frame `Focus`** — ลืมบ่อยที่สุด

## 9 · Anti-patterns

| ❌ | ✅ | ทำไม |
|---|---|---|
| ใช้ `<GrantCard>` กับสินเชื่อดอกเบี้ย 0% | `<FundingCard>` | ยังต้องคืนเงินต้น — ความผิดพลาดที่แพงที่สุดที่เป็นไปได้ |
| **เดา `collateral: 'none'` เมื่อ API ไม่ส่งมา** | `null` | บอกผู้ใช้ว่ากู้ได้โดยไม่ต้องมีหลักประกัน ซึ่งอาจไม่จริง (ข้อ 01 §4.1) |
| เดา `interestRate: 0` เมื่อไม่รู้ | `null` | "ไม่มีดอกเบี้ย" กับ "ยังไม่ประกาศ" คนละเรื่อง |
| `label` ย่อเหลือ "วงเงินสูงสุด" | `"วงเงินกู้สูงสุด"` | คำว่า "กู้" คือทั้งหมดของความต่างจากทุน |
| `collateral` เป็น `boolean` | union 3 ค่า | เคส บสย. หายไป → SME ที่กู้ได้จริงเลิกสนใจ |
| `"3%"` ไม่มีหน่วยเวลา | `"3% ต่อปี"` | ต่อเดือนกับต่อปีต่างกัน 12 เท่า |
| ซ่อนเงื่อนไขหลักประกันในหน้ารายละเอียด | บนการ์ด | ตัวตัดสินอันดับ 1 ว่ากู้ได้จริงไหม (B1) |
| เอาไปใช้กับทุนให้เปล่าเพราะ "ก็เป็นเงินเหมือนกัน" | `<GrantCard>` | ทำให้ทุนดูเหมือนหนี้ — ผู้ใช้ที่ควรสมัครจะไม่สมัคร |
