# ProgramCard

**`@smego/ui`** · ชั้น 03 · [ProgramCard.tsx](./ProgramCard.tsx) · ฐาน: [EntityCard.md](./EntityCard.md)

---

## 1 · ภาพรวม

การ์ดโครงการภาครัฐ — โครงการยกระดับ · จับคู่ธุรกิจ · พาไปออกงาน · ที่ปรึกษาฟรี

ความต่างหลักจากการ์ดอื่น: **ไม่มีจำนวนเงิน** และ **หน่วยงานเป็นข้อมูลความน่าเชื่อถือ**

### ❌ เมื่อไรที่ไม่ควรใช้

| สถานการณ์ | ใช้อะไรแทน |
|---|---|
| โครงการที่ให้ **เงิน** | `<GrantCard>` |
| หลักสูตรอบรมที่มีกำหนดการ | `<TrainingCard>` |
| บริการเอกชน | `<ServiceCard>` |

**เส้นแบ่งกับ `GrantCard`:** ถ้าสิ่งที่ผู้สมัครได้รับคือ **เงินหรือวงเงิน** ให้ใช้ GrantCard · ถ้าเป็นที่ปรึกษา พื้นที่ออกงาน การจับคู่ หรือการรับรอง ให้ใช้ ProgramCard

## 2 · React API

```tsx
<ProgramCard
  as="li"
  href="/programs/sme-transform-2569"
  name="โครงการยกระดับผู้ประกอบการสู่ตลาดสากล ปี 2569"
  agency="สำนักงานส่งเสริมวิสาหกิจขนาดกลางและขนาดย่อม"
  eligibility="นิติบุคคลจดทะเบียนในไทย ยอดขายไม่เกิน 500 ล้านบาทต่อปี"
  deadline="2026-12-31"
  status="open"
/>
```

| prop | type | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|---|
| `href` · `name` | `string` | — | **บังคับ** |
| `agency` | `string` | — | **บังคับ** — ดู §5 |
| `eligibility` | `string` | — | สรุปสั้น ไม่ใช่เกณฑ์เต็ม |
| `deadline` | `string` | — | ISO `YYYY-MM-DD` (ค.ศ.) |
| `status` | `'open' \| 'closing-soon' \| 'closed'` | — | **บังคับ · เป็น prop ไม่ใช่ค่าคำนวณ** |
| `daysLeft` | `number` | — | แสดงเมื่อ `closing-soon` |
| `media` · `actions` · `footer` | `ReactNode` | — | |

## 3 · Variants

ไม่มี variant — ความต่างมาจาก `status` ซึ่งจัดการโดย [`<DeadlineBadge>`](./Deadline.md)

| `status` | Badge | ไอคอน |
|---|---|---|
| `open` | `success` | วงกลม |
| `closing-soon` | `warning` | **สามเหลี่ยม** |
| `closed` | `danger` | วงกลม + กากบาท |

### ★★ **ไม่มี slot `amount` เลย** — และนั่นคือความต่างหลักจาก GrantCard

โครงการรัฐจำนวนมากให้ **สิ่งที่ไม่ใช่เงิน**: ที่ปรึกษา · การจับคู่ธุรกิจ · พื้นที่ออกงาน · การรับรองมาตรฐาน

ถ้าการ์ดมีช่องราคาว่างไว้ **ผู้ใช้จะคิดว่าข้อมูลไม่ครบ** และอาจข้ามโครงการที่เหมาะกับตัวเองไป

จึง **ตัด slot `amount` ออกทั้งหมด** ไม่ใช่ส่งค่าว่างเข้าไป — component ไม่ส่ง prop นั้นให้ `EntityCard` เลย

## 4 · States

สืบทอดจาก `EntityCard` · `status` ไม่ใช่ state ของ component แต่เป็นข้อมูล

### ★ การ์ด `closed` ยังกดได้

ผู้ใช้ต้องดูได้ว่าโครงการที่ปิดไปแล้วมีเงื่อนไขอะไร เพื่อเตรียมตัวสำหรับรอบหน้า — ซึ่งเป็นพฤติกรรมจริงบนแพลตฟอร์มรัฐที่โครงการมักเปิดเป็นรอบปี

## 5 · Accessibility

| เรื่อง | ข้อกำหนด |
|---|---|
| **SC 1.4.1** | สถานะมีรูปทรงจาก `<DeadlineBadge>` |
| **SC 1.3.1** | หน่วยงาน · กำหนด · คุณสมบัติ อยู่ใน `<dl>` |
| วันที่ | **พ.ศ.** ผ่าน `<DeadlineText>` — วัดแล้วได้ `31 ธ.ค. 2569` / `dateTime="2026-12-31"` |
| ทั่วไป | ดู [EntityCard.md §5](./EntityCard.md) |

### ★★ หน่วยงานคือข้อมูลความน่าเชื่อถือ ไม่ใช่ metadata

บนแพลตฟอร์มภาครัฐ ผู้ใช้ตัดสินใจจาก **"ใครเป็นเจ้าของโครงการ"** ก่อนอ่านรายละเอียด

สสว. กับ กรมส่งเสริมอุตสาหกรรม มีเงื่อนไข ความเข้มงวด และความเร็วในการอนุมัติต่างกัน — ผู้ประกอบการที่เคยผ่านมาแล้วรู้ดี

หน่วยงานจึงอยู่ **บรรทัดแรกของ `meta`** ไม่ใช่ท้ายสุด

⚠️ ชื่อหน่วยงานไทยยาวมาก ("สำนักงานส่งเสริมวิสาหกิจขนาดกลางและขนาดย่อม" = 43 ตัวอักษร) — ที่ 136px จะ wrap หลายบรรทัด **ซึ่งยอมรับได้** เพราะ `<dl>` ไม่ตัดข้อความ

### ★★ คุณสมบัติผู้สมัครถูกตัดที่ 2 บรรทัด **โดยตั้งใจ**

เกณฑ์เต็มยาวเกินกว่าจะอยู่ในการ์ด และ **การอ่านครึ่งเดียวอันตรายกว่าไม่อ่าน** — ผู้ประกอบการที่อ่าน "ยอดขายไม่เกิน 500 ล้าน" แล้วไม่เห็นข้อ "ต้องไม่เคยเข้าร่วม" จะเสียเวลาสมัคร

การ์ดบอกแค่ **"มีเงื่อนไข"** แล้วให้ไปอ่านเต็มในหน้ารายละเอียด

⚠️ `line-clamp-2` ที่นี่ **ปลอดภัย** เพราะไม่มี element ที่ focus ได้อยู่ข้างใน — ต่างจากชื่อการ์ดที่ต้องใช้ `data-focus-ring="deferred"`

## 6 · Tailwind implementation

```tsx
meta={
  <EntityMeta
    items={[
      /* หน่วยงานมาก่อน — เป็นข้อมูลความน่าเชื่อถือ */
      { label: s.card.agency, value: agency },
      { label: s.card.deadline, value: <DeadlineText date={deadline} /> },

      }] : []),
    ]}
  />
```

## 7 · Figma Variant

Component **`ProgramCard`**

| Property | Values |
|---|---|
| `Status` | `Open` · `Closing soon` · `Closed` |
| `Eligibility` | `True` · `False` |
| `Media` | `True` · `False` |

**ห้ามมี property `Price` หรือ `Amount`** — ถ้ามีคนขอ ให้ชี้ว่านั่นคือ `GrantCard`

**ตัวอย่างต้องใช้ชื่อหน่วยงานเต็มจริง** ("สำนักงานส่งเสริมวิสาหกิจขนาดกลางและขนาดย่อม") ไม่ใช่ตัวย่อ — เพื่อให้เห็นว่า wrap กี่บรรทัดที่ 136px

## 8 · Usage

```tsx
<Grid as="ul" preset="cards">
  {programs.map((p) => (
    <ProgramCard
      key={p.id}
      as="li"
      href={`/programs/${p.slug}`}
      name={p.name}
      agency={p.agency}
      eligibility={p.eligibilitySummary}
      deadline={p.closesAt}
      /* status คำนวณที่ฝั่งข้อมูลตามกฎของโครงการนั้น */
      status={p.status}
      daysLeft={p.daysLeft}
      footer={<Button size="sm" fullWidth isDisabled={p.status === 'closed'}>
        {p.status === 'closed' ? 'ดูเงื่อนไข' : 'สมัครเข้าร่วม'}
      </Button>}
    />
  ))}
</Grid>
```

## 9 · Anti-patterns

| ❌ | ✅ | ทำไม |
|---|---|---|
| ใส่ `amount` ว่าง ๆ ไว้ | ไม่ส่ง `amount` | ช่องราคาว่างอ่านว่าข้อมูลไม่ครบ |
| ใช้ ProgramCard กับทุนที่ให้เงิน | `<GrantCard>` | วงเงินและสัดส่วนร่วมจ่ายจะหายไป |
| คำนวณ `status` จากวันที่ในการ์ด | รับเป็น prop | SSR mismatch + "ใกล้ปิด" คือกฎธุรกิจ |
| แสดงเกณฑ์คุณสมบัติเต็มบนการ์ด | `line-clamp-2` + หน้ารายละเอียด | อ่านครึ่งเดียวอันตรายกว่าไม่อ่าน |
| หน่วยงานอยู่ท้าย meta | บรรทัดแรก | เป็นข้อมูลความน่าเชื่อถือ ไม่ใช่ footnote |
| ย่อชื่อหน่วยงานให้พอดีการ์ด | ปล่อยให้ wrap | ตัวย่อที่ผู้ใช้ไม่รู้จักแย่กว่ายาว |
| ปิดการ์ดที่ `closed` | ปล่อยให้กดได้ | ผู้ใช้เตรียมตัวสำหรับรอบหน้า |
| วันที่เป็น ค.ศ. | `<DeadlineText>` | 2026 ในบริบทราชการอ่านผิดทันที |

## 10 · Quality Checklist

**หลักฐาน ไม่ใช่ความตั้งใจ** — ทุกแถวชี้ไปที่หัวข้อในไฟล์นี้หรือชื่อเทสที่รันได้จริง ไม่มีแถวไหนอธิบายพฤติกรรมซ้ำ (นั่นคืองานของ §4 และ §5)

| รายการ | สถานะ | หลักฐาน |
|---|---|---|
| การเข้าถึง (Accessibility) | ✅ | §5 · axe ผ่านใน `a11y/marketplace.test.tsx` · `SC 1.4.1` สถานะปิดรับบอกด้วย**ข้อความใน [`<DeadlineBadge>`](./Deadline.md)** ไม่ใช่สีอย่างเดียว |
| ตอบสนอง (Responsive) | ✅ | สืบทอดจาก [`EntityCard`](./EntityCard.md) — ทดสอบที่ **136px** ตาม §7 ของไฟล์นั้น |
| โหมดมืด (Dark Mode) | ✅ | โครงและเงามาจาก [`EntityCard`](./EntityCard.md) → `<Card>` ซึ่งใช้ `--elevation-*` ไม่ใช่ `shadow-*` · `lint-classes.mjs` 0 จุด — ทุกสีมาจาก token ที่ override ในโหมดมืดแล้ว |
| คุณสมบัติเชิงตรรกะ (Logical properties) | ✅ | `lint-quality.mjs` 0 จุด — ไม่มี `ml-`/`pl-`/`left-` ในไฟล์นี้ |
| คีย์บอร์ด (Keyboard) | ✅ | สืบทอดจาก [`EntityCard §5`](./EntityCard.md) — link overlay เป็น `<a href>` จริงจึงอยู่ใน tab order ตามธรรมชาติ · วงแหวน focus วาดที่**การ์ด** ไม่ใช่ที่ลิงก์ (SC 2.4.7) |
| กำลังโหลด (Loading) | — | §4 ของ [`EntityCard`](./EntityCard.md) — ผู้เรียกครอบกริดด้วย [`<SkeletonGroup>`](../feedback/Skeleton.md) |
| ข้อผิดพลาด (Error) | — | การ์ดไม่ทำ async |
| ว่างเปล่า (Empty) | — | **ไม่มี slot `amount` โดยตั้งใจ** — โครงการไม่มีจำนวนเงิน มีแต่กำหนดปิดรับ ([`EntityCard §3`](./EntityCard.md)) · นี่คือการละเว้นที่ประกาศไว้ ไม่ใช่ช่องว่าง |
| Skeleton | — | ตัวแทนระหว่างโหลดอยู่ที่ระดับกริด |
| การเคลื่อนไหว (Animation) | ✅ | ไม่มี `transition` หรือ `animate` ในไฟล์นี้เลย — การเคลื่อนไหวเดียวคือ `transition-shadow` ที่สืบทอดมาจาก `<Card interactive>` ซึ่ง `box-shadow` อยู่ในรายการ ALLOW ของ `base.css §10` |
| ประสิทธิภาพ (Performance) | ✅ | สืบทอดจาก [`EntityCard §10`](./EntityCard.md) — `mt-auto` แทนการวัดความสูงด้วย JS · container query แทน ResizeObserver · ไม่มีความสูงตายตัว |
