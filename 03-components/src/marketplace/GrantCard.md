## 1 · ภาพรวม

การ์ดแหล่งทุน — **เงินที่ผู้รับไม่ต้องคืนเงินต้น** · ทุนสนับสนุน · เงินอุดหนุน · เงินร่วมจ่าย

**เป็นการ์ดที่ความผิดพลาดมีต้นทุนสูงที่สุดในระบบ** เพราะตัวเลขบนการ์ดถูกอ่านเป็นเงินที่จะได้รับ ทั้งที่ไม่ใช่

### ★★★ เส้นแบ่งกับ `FundingCard`

> **ผู้รับต้องคืนเงินต้นหรือไม่**
> ไม่คืน → `GrantCard` · คืน → [`FundingCard`](./FundingCard.md)
> **เมื่อไม่แน่ใจ ใช้ `FundingCard`**

> **📌 แก้ขอบเขต** — ฉบับแรกเขียนว่าการ์ดนี้ครอบคลุม *"ทุนสนับสนุน · เงินอุดหนุน · **สินเชื่อดอกเบี้ยพิเศษ**"*
>
> ข้อสามถูกตัดออก · การรวมเงินให้เปล่ากับหนี้ไว้ในการ์ดเดียวทำให้ทั้งสองแสดงด้วยรูปแบบเดียวกันเป๊ะ (`วงเงินสูงสุด 500,000`) — ผู้ใช้ที่กวาดตาผ่านหน้ารวมที่มีทั้งสองปนกัน **แยกไม่ออกว่าอันไหนต้องคืน**
>
> ตลกร้ายคือการ์ดนี้บังคับ `coPaymentPercent` ให้ส่งเสมอแม้เป็น 0 ด้วยเหตุผล *"ไม่แสดง ≠ 0%"* แต่กลับไม่เคยมี prop ใดบอกว่าเงินก้อนนี้ต้องคืนหรือไม่ — ซึ่งเป็นข้อมูลที่เปลี่ยนคำตอบมากกว่าสัดส่วนร่วมจ่ายเสียอีก (B1 · A4)

### ❌ เมื่อไรที่ไม่ควรใช้

| สถานการณ์ | ใช้อะไรแทน |
|---|---|
| **เงินที่ต้องคืนเงินต้น รวมสินเชื่อดอกเบี้ย 0%** | [`<FundingCard>`](./FundingCard.md) |
| โครงการที่ไม่ให้เงิน | `<ProgramCard>` |
| หลักสูตรที่มีทุนเรียน | `<TrainingCard>` |
| สินเชื่อเชิงพาณิชย์ปกติ | `<ProductCard>` ของสถาบันการเงิน |


## 3 · Variants

ไม่มี variant · ความต่างมาจาก `status` ผ่าน [`<DeadlineBadge>`](./Deadline.md)

### ★★★ **"วงเงินสูงสุด" ไม่ใช่ "ราคา"** — จุดที่ผิดพลาดแล้วเสียหายจริง

ตัวเลข **500,000 บาท** บนการ์ดแหล่งทุนหมายถึง **เพดานที่ขอได้** ไม่ใช่จำนวนที่จะได้รับ

ผู้สมัครส่วนใหญ่ได้น้อยกว่าเพดานมาก — บางรายได้ 80,000 จากเพดาน 500,000

`EntityAmount` บังคับ `label` เป็น prop จำเป็น และ GrantCard ส่ง `s.card.fundingCeiling` = **"วงเงินสูงสุด"** ซึ่ง **อยู่เหนือตัวเลขเสมอ** ไม่ใช่ต่อท้ายที่อาจถูกตัดที่ 136px

**ยืนยันจากการวัดที่ 136px:** `"วงเงินสูงสุด → 500,000"` — label อยู่ครบ ไม่ถูกตัด

### ★ ทองใช้ได้ที่นี่ — **CTA แหล่งทุนคือกรณีเดียวที่อนุญาต** (ข้อ 02 §9)

แต่ปุ่มมาจากผู้เรียกผ่าน `footer` — **การ์ดไม่บังคับสี** เพราะหน้ารวมที่มีทุก card ปนกันไม่ควรมีทองหลายใบแย่งกัน

## 5 · Accessibility

| เรื่อง | ข้อกำหนด |
|---|---|
| **SC 1.4.1** | สถานะมีรูปทรง |
| **SC 1.3.1** | หน่วยงาน · กำหนด · ร่วมจ่าย อยู่ใน `<dl>` |
| **SC 3.3.2** | label ของจำนวนเงินบอกความหมาย ไม่ใช่แค่ตัวเลข |
| วันที่ | **พ.ศ.** — วัดแล้ว `30 ก.ย. 2569` / `dateTime="2026-09-30"` |

### ★★★ สัดส่วนร่วมจ่ายต้องอยู่บนการ์ด ไม่ใช่ในหน้ารายละเอียด

ทุนที่ให้ **500,000 แต่ต้องร่วมจ่าย 50%** หมายความว่า SME ต้องมี **เงินสด 500,000 ของตัวเอง**

ซึ่ง **เปลี่ยนคำตอบว่า "สมัครได้ไหม" ทั้งหมด** — ผู้ประกอบการรายย่อยจำนวนมากผ่านเกณฑ์ทุกข้อยกเว้นข้อนี้

ข้อมูลที่เปลี่ยนการตัดสินใจขนาดนี้ **ห้ามซ่อน** (ข้อ 01 §4.3) และ **ห้ามอยู่ใน tooltip** เพราะผู้ใช้ touch เข้าไม่ถึง (SC 1.4.13 · ดู [Tooltip.md](../feedback/Tooltip.md))

### ★★ `coPaymentPercent` บังคับแม้เป็น `0`

**การไม่แสดงกับการแสดง "0%" ให้ข้อมูลต่างกันคนละเรื่อง:**

- ไม่แสดง → ผู้ใช้ไม่รู้ว่ามีเงื่อนไขนี้หรือเปล่า ต้องไปหาเอง
- แสดง "0%" → ผู้ใช้รู้แน่ชัดว่า **ไม่ต้องร่วมจ่าย** ซึ่งเป็นจุดขายของทุนนั้น

TypeScript บังคับให้ส่ง — ไม่มี `?`

## 7 · Figma Variant

Component **`GrantCard`**

| Property | Values |
|---|---|
| `Status` | `Open` · `Closing soon` · `Closed` |
| `Co-payment` | `0%` · `30%` · `50%` |

**`Co-payment` ต้องเป็น property ที่มองเห็นเสมอ ไม่ใช่ `True/False`** — ค่า `0%` ต้องแสดงจริง

**label "วงเงินสูงสุด" ห้ามย่อเป็น "วงเงิน"** — คำว่า "สูงสุด" คือทั้งหมดของความหมาย

**ตัวอย่างต้องมี frame ที่ 136px พร้อมเลข 6 หลัก** เพื่อพิสูจน์ว่า label ไม่ถูกตัด

## 9 · Anti-patterns

| ❌ | ✅ | ทำไม |
|---|---|---|
| `label="ราคา"` หรือไม่มี label | `"วงเงินสูงสุด"` | ผู้ใช้อ่านเป็นเงินที่จะได้รับ — เสียหายทางการเงินจริง |
| ย่อเป็น "วงเงิน" | เต็มว่า "วงเงินสูงสุด" | คำว่า "สูงสุด" คือทั้งหมดของความหมาย |
| `coPaymentPercent` เป็น optional | บังคับเสมอ | ไม่แสดง ≠ 0% |
| สัดส่วนร่วมจ่ายใน tooltip | ใน `meta` ของการ์ด | ผู้ใช้ touch เข้าไม่ถึง (SC 1.4.13) |
| สัดส่วนร่วมจ่ายในหน้ารายละเอียดอย่างเดียว | บนการ์ด | เปลี่ยนคำตอบว่า "สมัครได้ไหม" |
| ปุ่มทองบนทุกการ์ดในหน้ารวม | ทองเฉพาะ CTA แหล่งทุน | ทองหลายใบแย่งกัน = ไม่มีอะไรเด่น |
| ใช้ GrantCard กับโครงการที่ไม่ให้เงิน | `<ProgramCard>` | ช่องวงเงินว่างอ่านว่าข้อมูลไม่ครบ |
| label ต่อท้ายตัวเลข | เหนือตัวเลข | ที่ 136px ท้ายบรรทัดถูกตัดก่อน |
