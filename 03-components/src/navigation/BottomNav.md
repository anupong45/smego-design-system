# BottomNav

> แถบนำทางยึดก้นจอ **บนมือถือเท่านั้น** — ประกาศ `--bottom-nav-height` ของตัวเอง

---

## 1 · เมื่อไหร่ใช้ และเมื่อไหร่ไม่ใช้

| | ใช้ |
|---|---|
| นำทางระดับบนสุด 3–5 ปลายทาง บนมือถือ | `<BottomNav>` |
| นำทางระดับบนสุดบนเดสก์ท็อป | [`<TopNav>`](./TopNav.md) — แถบนี้ `md:hidden` |
| สลับมุมมองของ **เนื้อหาเดียวกัน** | [`<TabList>`](./TabList.md) หรือ [`<SegmentedControl>`](./SegmentedControl.md) |
| ปุ่มยืนยันที่ต้องค้างก้นจอ | action bar ของหน้านั้น (`--action-bar-height`) |
| แถบเปรียบเทียบสินค้า | [`<CompareBar>`](../marketplace/Compare.md) |

⚠️ **ห้ามใช้เป็นตัวกรอง** — แถบนี้เปลี่ยน **หน้า** ไม่ใช่เปลี่ยนสิ่งที่แสดงในหน้าเดิม ถ้าเป็นการกรองให้ใช้ [`<Token>`](../data-display/Token.md) หรือ [`<FilterPanel>`](../marketplace/FilterPanel.md) — เหตุผลเดียวกับที่ [`<Switch>`](../inputs/Switch.md) ห้ามเป็นตัวกรอง

---

## 2 · Props

| prop | type | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|---|
| `items` | 1–5 รายการ | — | **บังคับ** — type ปฏิเสธเกิน 5 (ดู §3) |
| `label` | `string` | `"เมนูหลัก"` | ชื่อ landmark · **ต้องต่างกัน** ถ้าหน้ามี `<nav>` อื่น |
| `reserveSpace` | `boolean` | `true` | ประกาศความสูงเข้า `--bottom-nav-height` |

### `BottomNavItem`

| field | type | หมายเหตุ |
|---|---|---|
| `label` | `string` | **สั้น** คำเดียวหรือสองคำ (ดู §3) |
| `icon` | `IconName` | key จาก [registry](../icon/Icon.md) |
| `href` | `string` | ใช้เป็น key ด้วย จึงต้องไม่ซ้ำ |
| `isCurrent` | `boolean` | ได้ `aria-current="page"` |
| `count` | `number` | ตัวเลขมุมขวา เช่นจำนวนในตะกร้า |

---

## 3 · สูงสุด 5 รายการ — บังคับด้วย type

ไม่ใช่คำเตือนในเอกสารที่ใครก็ข้ามได้ · `items` เป็น tuple union ขนาด 1–5 ดังนั้นรายการที่ 6 **คอมไพล์ไม่ผ่าน**

วัดที่ 320px ซึ่งเป็นจอแคบสุดที่ระบบนี้รองรับ:

| จำนวน | ความกว้างต่อช่อง | ผล |
|---|---|---|
| 4 | 80px | สบาย |
| 5 | 64px | พอสำหรับ "หน้าแรก" · "ตะกร้า" · "รายการโปรด" |
| 6 | 53px | **ต้องตัดคำ** |

ข้อความไทยยาวกว่าอังกฤษ 20–40% — ป้ายที่ตัดคำแล้วอ่านไม่ออกก็ไม่ต่างจากไม่มีป้าย และการซ่อนป้ายเหลือแต่ไอคอนก็ไม่ใช่ทางออก เพราะข้อ 09 อนุญาตไอคอนล้วนเฉพาะ 5 ตัวที่เป็นสัญลักษณ์สากลจริง

---

## 4 · หน้าปัจจุบันบอกด้วยสองอย่าง ไม่ใช่สีเดียว

| ตัวชี้ | ทำอะไร |
|---|---|
| `aria-current="page"` | ประกาศให้ screen reader |
| **ขีดบนขอบล่างของช่อง** | ตัวชี้ที่ไม่ใช่สี — SC 1.4.1 |
| สีข้อความ `text-selected-fg` | เสริม ไม่ใช่ตัวเดียว |

★ ใช้ `aria-current="page"` **ไม่ใช่ `aria-selected`** — นี่คือลิงก์ที่พาไปหน้าอื่น ไม่ใช่ tab ที่สลับเนื้อหาในหน้าเดิม `aria-selected` จะทำให้ screen reader ประกาศบทบาทผิด

---

## 5 · จำนวนต้องมีหน่วย

```tsx
{ label: 'ตะกร้า', icon: 'shopping-cart', href: '/cart', count: 3 }
```

| | ได้อะไร |
|---|---|
| ตา | ป้าย "ตะกร้า" + ตัวเลข `3` ที่มุม |
| screen reader | **"ตะกร้า 3 รายการ"** |

ตัวเลขที่เห็นด้วยตาเป็น `aria-hidden` เพราะจำนวนอยู่ในชื่อ accessible แล้ว ถ้าไม่ซ่อนจะได้ยิน "ตะกร้า 3 รายการ 3"

หลักเดียวกับจำนวนในตะกร้าของ [`TopNav`](./TopNav.md) และปุ่มลบของ [`RemovableChip`](../data-display/Token.md) — **ตัวเลขลอย ๆ ไม่บอกอะไร**

เกิน 99 แสดง `99+` ที่ตา แต่ชื่อ accessible ยังเป็นเลขจริง

## 6 · การจองพื้นที่ก้นจอ (SC 2.4.11)

```tsx
useLayoutEffect(() => {
  root.style.setProperty('--bottom-nav-height', `${el.offsetHeight}px`);
  // cleanup → '0px'  ไม่ใช่ removeProperty
}, [...]);
```

★★★ ประกาศ **เฉพาะตัวแปรของตัวเอง** · `--bottom-inset` ใน [`semantic.css`](../../../02-tokens/src/semantic.css) รวมทุกแถบด้วย `calc()` แล้ว `base.css §5a` จองพื้นที่ท้ายเอกสารจากค่านั้น

```css
--bottom-inset: calc(
  var(--bottom-nav-height) + var(--compare-bar-height) + var(--action-bar-height)
);
```

⚠️ นี่คือบั๊กที่ [`CompareBar`](../marketplace/Compare.md) **เคยเป็น** — เขียนทับ `--bottom-nav-height` ของแถบอื่นและ `body.style.paddingBottom` ตรง ๆ แล้ว last-writer-wins ทำให้จองพื้นที่แค่แถบเดียว ปุ่มท้ายหน้าจมใต้แถบ · **มองไม่เห็นเลยจนกว่าจะมีสองแถบพร้อมกัน** ซึ่งเป็นเหตุที่ `lint-classes.mjs` ปฏิเสธการเขียน `body.style.padding*` จาก component

| จุดที่ต้องระวัง | ทำไม |
|---|---|
| `useLayoutEffect` ไม่ใช่ `useEffect` | ค่าต้องถูกตั้งก่อน paint ไม่เช่นนั้นเฟรมแรกไม่มีพื้นที่จอง แล้วหน้ากระตุก |
| cleanup คืน `'0px'` ไม่ใช่ `removeProperty` | ถ้าลบทิ้ง `calc()` คำนวณไม่ได้ทั้งก้อน พื้นที่จองของแถบอื่นหายไปด้วย |
| `ResizeObserver` | ความสูงเปลี่ยนจริงเมื่อป้ายขึ้นบรรทัดที่สองบนจอแคบ |

### safe area ของ iOS

`pb-[env(safe-area-inset-bottom,0px)]` — ไม่เผื่อจะถูก home indicator ทับ (ข้อ 08 §5.2)

## 7 · เป้ากด 56px

สูงกว่าเกณฑ์ 44px ของ SC 2.5.8 โดยตั้งใจ เพราะแถบก้นจอถูกกดด้วย **นิ้วโป้งขณะถือมือเดียว** ซึ่งแม่นน้อยกว่าการกดด้วยนิ้วชี้ · เป็นเหตุผลเดียวกับที่ปุ่มของระบบนี้อยู่ที่ 38/46 ไม่ใช่ 28/32/36 ของ Astryx (**D1**)

---

## 8 · ชื่อ landmark ต้องไม่ซ้ำ

ถ้าหน้ามี `<nav>` มากกว่าหนึ่ง — ซึ่งเกิดจริงเมื่อมี `TopNav` + `BottomNav` + [`Pagination`](./Pagination.md) — **ทุกตัวต้องมีชื่อต่างกัน** ไม่เช่นนั้น axe ฟ้อง `landmark-unique` และผู้ใช้ screen reader แยกไม่ออกว่าอันไหนคืออันไหน

```tsx
<BottomNav items={items} label="เมนูหลักบนมือถือ" />
```

เคสเดียวกับ Pagination บน+ล่างในหน้าเดียว — ล็อกไว้ด้วยเทสแล้ว

---

## 9 · กับดัก

| อย่าทำ | ทำแบบนี้ | เพราะ |
|---|---|---|
| 6 รายการขึ้นไป | ≤5 · ที่เหลือไว้ในเมนู | 53px ต่อช่องต้องตัดคำ (§3) |
| ซ่อนป้ายเหลือแต่ไอคอน | คงป้ายไว้ | ไอคอน 5 ตัวเรียงกันโดยไม่มีคำกำกับทำให้ต้องเดา |
| ใช้บนเดสก์ท็อป | `TopNav` | สองแถบ = เมนูหลักสองชุดในหน้าเดียว |
| ใช้เป็นตัวกรอง | `Token` / `FilterPanel` | แถบนี้เปลี่ยนหน้า ไม่ใช่เปลี่ยนเนื้อหาในหน้า |
| `count` แล้วเขียน label เอง | ปล่อยให้ component ประกอบ | จะได้ "ตะกร้า 3 รายการ 3" |
| แตะ `--compare-bar-height` หรือ `body.style` | ตัวแปรของตัวเองเท่านั้น | last-writer-wins (§6) — linter ปฏิเสธ |
| บอกหน้าปัจจุบันด้วยสีเดียว | ขีด + `aria-current` | SC 1.4.1 |

## 10 · Quality Checklist

**หลักฐาน ไม่ใช่ความตั้งใจ** — ทุกแถวชี้ไปที่หัวข้อในไฟล์นี้หรือชื่อเทสที่รันได้จริง

| รายการ | สถานะ | หลักฐาน |
|---|---|---|
| การเข้าถึง (Accessibility) | ✅ | §4 §5 §8 · axe ผ่านใน `a11y/bottomnav.test.tsx` · เทส "aria-current ไม่ใช่ aria-selected" · "จำนวนมีหน่วยในชื่อ" · "ตัวชี้ที่ไม่ใช่สี" · "สอง nav ชื่อซ้ำ = landmark-unique" |
| ตอบสนอง (Responsive) | ✅ | `md:hidden` — มือถือเท่านั้น · `flex-1` + `truncate` · จำกัด 5 รายการด้วย type จากการวัดที่ 320px (§3) |
| โหมดมืด (Dark Mode) | ✅ | `lint-classes.mjs` 0 จุด — พื้นใช้ `--elevation-surface-overlay` ที่ override ในโหมดมืดแล้ว · อยู่ใน contrast sweep ทั้งสองโหมด |
| คุณสมบัติเชิงตรรกะ (Logical properties) | ✅ | `lint-quality.mjs` 0 จุด — `-end-2` ไม่ใช่ `-right-2` · `inset-x-3` |
| คีย์บอร์ด (Keyboard) | ✅ | `<a href>` ทุกตัวเป็น tab stop ตามลำดับเอกสาร · ไม่มี roving tabindex เพราะนี่คือลิงก์ ไม่ใช่ชุดตัวเลือก |
| กำลังโหลด (Loading) | — | แถบนำทางไม่มีสถานะโหลดของตัวเอง — การเปลี่ยนหน้าเป็นเรื่องของ router |
| ข้อผิดพลาด (Error) | — | ไม่มีสถานะผิดพลาดของตัวเอง |
| ว่างเปล่า (Empty) | — | type บังคับ ≥1 รายการ — แถบเปล่าที่ก้นจอกินพื้นที่โดยไม่ให้อะไร |
| Skeleton | — | ความสูงคงที่ 56px + safe area · ไม่ทำให้ CLS |
| การเคลื่อนไหว (Animation) | ✅ | `transition-colors` เท่านั้น — อยู่ในรายการ ALLOW ของ reduced motion (`base.css §10`) · ไม่มี transform |
| ประสิทธิภาพ (Performance) | ✅ | `useLayoutEffect` + `ResizeObserver` ประกาศเฉพาะตัวแปรตัวเอง — เทส "ไม่แตะ body.style" และ "ไม่ทับ --compare-bar-height" · `min-h` ไม่ใช่ `h` |
