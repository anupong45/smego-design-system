# Spinner

**`@smego/ui`** · ชั้น 03 · [Spinner.tsx](./Spinner.tsx)

> สร้างใหม่ในเฟส 5 ตาม ASTRYX-PARITY.md §1.3 · เขตแดนกับ `Skeleton` ตัดสินไว้ใน §8.5

## 1 · ภาพรวม

ตัวหมุนสำหรับ **การกระทำที่รอผลโดยไม่รู้เวลา** — ไม่ใช่การโหลดเนื้อหา

### ★★★ เขตแดนกับ [`<Skeleton>`](./Skeleton.md) — ตัดสินไว้แล้ว (ASTRYX-PARITY.md §8.5)

| | ใช้เมื่อ |
|---|---|
| [**`Skeleton`**](./Skeleton.md) | โหลด**เนื้อหาที่รู้รูปร่างล่วงหน้า** — การ์ด รายการ ตาราง |
| **`Spinner`** | **การกระทำที่รอผลโดยไม่รู้เวลา** — ปุ่มกำลัง submit, ยืนยันการชำระเงิน |

**ห้ามใช้ `Spinner` แทนการโหลดเนื้อหา** และห้ามใช้ `Skeleton` กับการกระทำ

เหตุผลที่กฎนี้ต้องเขียนไว้ทั้งสองไฟล์: ตัวหมุนกลางหน้าเปล่าบอกผู้ใช้ว่า "รอ" โดยไม่บอกว่ารออะไรและจะได้อะไร ส่วน skeleton ที่ค้างหลังกดปุ่มบอกว่า "เนื้อหากำลังมา" ทั้งที่ความจริงคือคำสั่งกำลังถูกประมวลผล — ทั้งสองแบบทำให้ผู้ใช้รอของที่ไม่มีอยู่

### ❌ เมื่อไรที่ไม่ควรใช้

| สถานการณ์ | ใช้อะไรแทน | เหตุผล |
|---|---|---|
| โหลดเนื้อหาที่รู้รูปร่าง | [`<Skeleton>`](./Skeleton.md) | ดูเขตแดนด้านบน |
| รู้ความคืบหน้าเป็นตัวเลข | [`<ProgressBar>`](./ProgressBar.md) | ตัวหมุนไม่บอกว่าเหลืออีกเท่าไร |
| ปุ่มกำลังทำงาน | `<Button isLoading>` | `Button` ใส่ตัวหมุนให้เองแล้ว และคง label ไว้ใน a11y tree |
| ช่องกรอกกำลังตรวจค่า | `<TextInput isLoading>` | จัดตำแหน่งในกล่องให้แล้ว |
| โหลดเร็วกว่า ~300ms | ไม่ต้องแสดงอะไร | กระพริบเข้า-ออกรบกวนกว่าการรอเงียบ |

## 2 · React API

```tsx
import { Spinner } from '@smego/ui';

// รอผลที่ผู้ใช้ต้องรู้ว่ารออะไร
<Spinner label="กำลังยืนยันการชำระเงิน" />

// ไม่มีที่ว่างให้ข้อความ แต่ยังต้องประกาศ
<Spinner size="sm" shade="subtle" label="กำลังตรวจสอบ" isLabelHidden />
```

| prop | type | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|---|
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'md'` | 16 / 20 / 24 / 32px — ผูกกับสเกลไอคอน |
| `shade` | `'default' \| 'onMedia' \| 'subtle' \| 'inherit'` | `'default'` | ดู §3 |
| `label` | `string` | — | **ไม่ส่ง = ของตกแต่ง** ดู §5 |
| `isLabelHidden` | `boolean` | `false` | `sr-only` แต่ยังประกาศ |
| `className` | `string` | — | |

## 3 · Variants

### ขนาด — ผูกกับสเกลไอคอน ไม่ใช่ค่าของ Astryx

| | เรา | Astryx |
|---|---|---|
| `sm` | **16px** | 10px |
| `md` | **20px** | 14px |
| `lg` | **24px** | 18px |
| `xl` | **32px** | 36px |

ค่าของเราคือขนาดที่ **มี stroke ล็อกไว้** ใน [`Icon`](../icon/Icon.md) แล้ว (`tokens.json` §icon) — 36px ของ Astryx ไม่มีค่า stroke ในระบบเรา และ 10px บางเกินกว่าจะผ่าน 3:1 บนจอ 1x DPI

### เฉดสี

| `shade` | คลาส | ใช้เมื่อ |
|---|---|---|
| `default` | `text-primary-600` | บนพื้นสว่างทั่วไป |
| `onMedia` | `text-on-brand` | บนพื้นทึบสีแบรนด์หรือรูปภาพ |
| `subtle` | `text-fg-muted` | ในรายการหรือในช่องกรอก — ไม่แย่งความสนใจ |
| `inherit` | *(ไม่ใส่คลาสสี)* | รับ `currentColor` ของพ่อแม่ |

**`inherit` มีไว้สำหรับปุ่ม** ที่พื้นเปลี่ยนตาม variant — วงแหวนจะตรงกับสีตัวอักษรที่ resolve แล้วเสมอ ไม่ต้องเดาว่าปุ่มนี้พื้นเข้มหรือสว่าง

## 4 · States

ไม่มี state ของตัวเอง — ตัวหมุนหมุนอยู่เสมอตลอดที่มันอยู่ใน DOM

การซ่อน/แสดงเป็นหน้าที่ของผู้เรียก (`{isPending && <Spinner …/>}`)

## 5 · Accessibility

| เรื่อง | ข้อกำหนด |
|---|---|
| role | `status` เมื่อมี `label` · ไม่มี role เลยเมื่อไม่มี `label` |
| **SC 4.1.3** | `role="status"` เป็น **polite** — การโหลดไม่ใช่เรื่องด่วน |
| **SC 1.1.1** | ไอคอนเป็น `aria-hidden` เสมอ — ข้อความคือตัวสื่อความหมาย |
| **SC 2.3.3** | ใช้ `.spinner` ที่อยู่ในรายการ ALLOW ของ reduced motion |
| **SC 2.2.1** | ไม่มีตัวจับเวลา — ไม่หายเอง |

### ★★★ สามโหมด และผู้เรียกต้องเลือกอย่างตั้งใจ

| ส่งอะไร | ผลลัพธ์ | ใช้เมื่อ |
|---|---|---|
| ไม่ส่ง `label` | `aria-hidden` ทั้งตัว — **ไม่ประกาศอะไร** | ผู้เรียกมีชื่ออยู่แล้ว เช่นใน `<Button isLoading>` ที่ข้อความปุ่มประกาศไปแล้ว |
| `label` | ข้อความเห็นได้ใต้ตัวหมุน + `role="status"` | รอผลที่ต้องบอกว่ารออะไร |
| `label` + `isLabelHidden` | `sr-only` + `role="status"` | ไม่มีที่ว่างให้ข้อความ เช่นในช่องกรอก |

**ตัวหมุนอย่างเดียวไม่สื่ออะไรกับผู้ใช้ screen reader** — โหมดแรกจึงเป็นการประกาศว่า "ผู้เรียกรับผิดชอบชื่อเอง" ไม่ใช่การละเลย ถ้าประกาศทั้งที่ปุ่มพูดไปแล้ว ผู้ใช้จะได้ยินซ้ำสองครั้ง

### ★★★ ต้องใช้ `.spinner` ไม่ใช่ `animate-spin`

`base.css §10` ปิด animation ทุกตัวด้วย `animation-iteration-count: 1 !important` แล้ว**คืนให้เฉพาะ `.spinner`** ในรายการ ALLOW เพราะเป็นการเคลื่อนไหวที่สื่อข้อมูลและกินพื้นที่เล็ก (ข้อ 07 §6.2)

⚠️ `animate-spin` ของ Tailwind **ไม่อยู่ในรายการนั้น** — ตัวที่ใช้มันจะหมุนรอบเดียวใน 1ms แล้วค้างเมื่อผู้ใช้เปิด reduced motion กลายเป็นไอคอนนิ่งที่ดูเหมือนของตกแต่ง **โดยไม่มี error ให้เห็น**

**พบจริงใน `TextInput.tsx`** ตอนสร้าง component นี้ — ตัวหมุนตอนตรวจเลขนิติบุคคลค้างนิ่งสำหรับผู้ใช้ reduced motion มาตลอด (`sr-only` ยังทำงาน จึงไม่มีใครสังเกต) แก้ไปแล้วด้วยการหันมาใช้ `<Spinner>`

## 6 · Tailwind implementation

```tsx
<Icon name="loader" size={ICON_SIZE[size]} aria-hidden="true"
  className={cn('spinner', SHADE[shade])} />
```

`.spinner` มาจาก `base.css` ไม่ใช่จากไฟล์นี้:

```css
.spinner { animation: sme-spin var(--transition-duration-slower) var(--ease-linear) infinite; }
```

ความเร็วจึงเป็น **ค่าของระบบ** ไม่ใช่ prop — ตัวหมุนสองตัวในหน้าเดียวกันต้องหมุนพร้อมกัน

## 7 · Figma Variant

Component set **`Spinner`**

| Property | Values |
|---|---|
| `Size` | `sm (16)` · **`md (20)`** · `lg (24)` · `xl (32)` |
| `Shade` | **`default`** · `onMedia` · `subtle` · `inherit` |
| `Label` | **`None`** · `Below` |

**ต้องเขียนใน description ว่าความเร็วมาจาก `--transition-duration-slower`** — ถ้านักออกแบบทำ prototype ที่เร็วกว่านี้ นักพัฒนาจะไปแก้ที่ component แล้วตัวหมุนทั้งระบบจะไม่ตรงกัน

**ห้ามสร้าง variant `Tone = Error`** — ตัวหมุนสีแดงคือ Banner ที่มาช้า

## 8 · Usage

```tsx
// รอยืนยันการชำระเงิน — ผู้ใช้ต้องรู้ว่าห้ามปิดหน้า
{isConfirming && (
  <Spinner size="lg" label={s.payment.confirming} />
)}
```

```tsx
// ในปุ่มที่ทำเอง (ปกติใช้ <Button isLoading> ซึ่งทำให้แล้ว)
<button className="bg-primary-600 text-on-brand …">
  <Spinner size="sm" shade="inherit" />
  กำลังบันทึก
</button>
```

```tsx
// ในแถวรายการที่กำลัง sync — subtle เพื่อไม่แย่งความสนใจจากเนื้อหา
<Spinner size="sm" shade="subtle" label={s.common.loading} isLabelHidden />
```

## 9 · Anti-patterns

| ❌ | ✅ | ทำไม |
|---|---|---|
| `animate-spin` | `<Spinner>` (ใช้ `.spinner`) | ค้างนิ่งใน reduced motion โดยไม่มี error |
| `<Spinner>` แทนกริดสินค้าที่กำลังโหลด | [`<Skeleton>`](./Skeleton.md) | §8.5 · ไม่บอกโครงสร้างที่จะมา |
| `<Spinner>` โดดๆ กลางหน้าเปล่า | + `label` บอกว่ารออะไร | "รอ" ที่ไม่บอกว่ารออะไรคือการขอให้เชื่อ |
| `<Spinner label>` ใน `<Button isLoading>` | ไม่ส่ง `label` | ปุ่มประกาศไปแล้ว — ได้ยินซ้ำสองครั้ง |
| `role="alert"` | `role="status"` | การโหลดไม่ใช่เรื่องด่วน ขัดสิ่งที่กำลังฟัง |
| `size={36}` | `size="xl"` (32) | 36px ไม่มี stroke ล็อกในระบบ |
| ตัวหมุนที่หายเองหลัง N วินาที | อยู่จนงานเสร็จ | SC 2.2.1 · งานยังไม่เสร็จแต่สัญญาณหาย |
